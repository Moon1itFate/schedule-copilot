# 液态玻璃界面

本次替换原有深色样式，重组为浮动工具栏、玻璃对话面板与周课表，并统一日程、待办、导入、设置、作息编辑和提醒预览的样式。移除「我的一周」标题及摘要区，功能主体直接从导航栏下方开始，减少装饰占用。

0.5.1 将整体配色更新为明亮暖色：奶油白与浅杏背景、珊瑚和陶土强调色、暖金与淡玫瑰课程卡片。原生状态栏、菜单、通知强调色和提醒胶囊一并同步。

`liquid-glass-react@1.1.1` 用于实际的 SVG 折射、背景模糊与边缘光学层。`src/components/GlassLens.tsx` 将玻璃底层与文字、输入框、按钮分离：鼠标在面板中移动时只有光学层响应，点击区域和文本位置不变。高频课表单元格使用轻量半透明材质，避免每个单元格单独挂载折射实例。

响应式布局覆盖 320px 至 1920px。小屏幕采用单行工具栏与抽屉对话面板，课表 / 日程 / 待办收进同一风格的下拉菜单，周数与功能按钮同行。左右滑动课表切换周次，纵向滚动不翻周；周数可点击回到本周，键盘聚焦课表后可用方向键切换，手机课表七天在一屏内等宽显示，时间栏分行显示开始与结束时间，课程名称自动换行；课表仅需纵向滚动，点击卡片查看和编辑完整信息。支持 `prefers-reduced-motion`，不支持背景模糊的浏览器回退到浅色实体底。Safari、Firefox 的折射效果受浏览器能力影响，参考[组件说明](https://github.com/rdev/liquid-glass-react)。

安卓 0.5.0 同步更新原生状态栏、导航栏、菜单与提醒胶囊配色。原生胶囊采用 Android 绘制，React 液态玻璃效果用于 WebView 页面。
