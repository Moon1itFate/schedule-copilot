# 日程与导入稳定性修复

## 已修复

- 本地助手把明确的“本周一”排到下周；查询“明天”混入未来一周的安排；晚上十二点被记成中午。明确本周按自然周解析，单日查询只返回当天，夜间十二点换算为次日零点。
- 前后端分别维护周次解析，混合单双周时可能返回空数组，文本导入还会漏掉“2-16双周”。现在共用周次解析，逐段处理单双周。
- 编辑待办时，空日期被前端当作未修改，保存后仍显示原时间；无截止日程打开后被填入默认截止。现在支持真正清空日期，并可编辑全天标记。
- API 和模型工具可能保存不存在的日期、反向时间段或部分有效的批量数据。现在共用校验，整次操作校验成功后才保存；失败时不污染当前状态。
- 等待模型回复时，手动新增的数据可能被旧状态覆盖。工具执行前读取最新状态，保留期间新增的内容。
- ICS 计算周次时忽略导入窗口填写的开学日期；预览接口仅返回单次日程数量，导致界面无法导入。现在按填写日期计算，课程和单次日程都可预览、勾选、提交。仅导入单次日程会保留当前课程。
- 本工具导出的 ICS 添加兼容的自定义元数据，重新导入可保留比赛类型、完成状态、全天标记、起止时间等信息，也能识别仅一周的课程。普通 ICS 的单次日程保留结束时间，不受学期范围限制。
- 聊天流不兼容 CRLF 换行、遗漏末尾事件，连接中断后发送状态可能卡住。现在处理这些情况并显示错误。
- 学期结束后翻周可能需要点击多次；中文输入法选词回车可能误发送。现在翻周受学期边界约束，并忽略输入法选词回车。
- 手机界面隐藏文字后，部分按钮没有可读名称。已补充课表、日程、待办与导入按钮的无障碍名称。
