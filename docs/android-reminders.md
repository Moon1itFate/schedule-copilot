# 安卓任务提醒与顶部胶囊

0.6.0 手机独立版直接读取本机任务，支持离线系统通知与顶部胶囊悬浮窗。胶囊显示在屏幕上方，可覆盖其它 App，点开任务后进入对应编辑窗；30 秒后自动收起，系统通知保留。采用 Android 标准悬浮窗实现，显示方式由本 App 绘制。

## 开启

1. 安装项目根目录的 `ScheduleCopilot.apk`，无需启动电脑服务。
2. App 齿轮设置 → **任务提醒 · 流动岛** → **设置手机提醒**。
3. 分别打开通知权限、悬浮窗权限和精确提醒权限。未允许悬浮窗时仍可发送系统通知；未允许精确提醒时使用系统非精确闹钟，可能延迟。
4. 勾选开启提醒，选择提前 5、10、15、30 或 60 分钟，按需勾选胶囊悬浮窗，点击保存。
5. 重新打开提醒设置，确认手机本地任务数量和最后读取时间，点 **试发一条提醒**。试发使用已保存的选项。

在电脑网页的设置中也可以点击 **预览流动岛提醒** 查看样式。网页预览仅在当前页面显示；跨 App 和后台提醒由安卓端实现。

## 调度规则

- 只提醒未完成且尚未到时的任务，不包含课表课程。开始时间优先；没有开始时间时取截止时间；全天任务按当天 09:00 提醒。
- 最近 100 个未来任务会缓存到手机。闹钟一次只安排下一次触发，同一触发时间内的任务合并处理，不靠常驻轮询服务维持计时。
- 每个任务按 ID 和时间去重。修改提醒提前量不会再次提醒已通知过的同一任务；任务改期后可重新提醒。
- 保存手机任务后直接重建提醒，不进行电脑网络轮询；原有后台同步任务会被取消。
- 完成、删除和改期后读取手机最新文件更新本地闹钟；手机与电脑各自保存数据，可通过 JSON 备份手动迁移。
- 通知里不会包含 API Key、模型配置或任务备注。点击通知或胶囊会打开对应任务；若任务已经被删除则进入待办列表。
- 手机重启、时间变更和 App 更新后从手机文件重建闹钟。关闭提醒会取消闹钟、当前悬浮窗。

## 系统限制

不同品牌的后台省电、通知横幅和悬浮窗策略不同；如未弹出，可在 App 的提醒设置中检查权限，在系统设置里允许后台运行，并确认没有强行停止 App。锁屏内容和勿扰模式遵循手机的通知设置。精确闹钟和浮窗均需用户授权；不保证绕过系统省电或强行停止限制。

本次已验证提醒数据接口、网页预览与任务跳转、纯 Java 闹钟规划、Android APK 编译及签名。没有连接安卓真机或模拟器，因此跨应用浮窗、厂商权限页面和锁屏投递需在安装后通过「试发一条提醒」验证。
